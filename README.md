# ZAN（斬）

斬って、進む。資格の勉強と、毎日のやることを一つにした手帳アプリ（PWA）。旧名は Certivo。

やることを済ませると「斬った」と数えて経験値が入り、問題で迷ったところからは毎週「影」が生まれます。影は正解するたびに削れ、倒すと図鑑に残ります。スマホでも PC でも、インストールしてアプリとして使えます。

## できること

- **今日**：今日のやることと、朝の欠片（5問）、週の影、AI の案（その日の短い練習）。一行で書くと「あした 19:00 歯医者」「10/31まで 住民税」「毎日 ストレッチ」のように日付や時刻を読み取ります
- **挑む**：週の影と戦う 4問。影の種類ごとに会心の条件があります
- **やること**：個人の手帳と仕事の手帳。仕事は経験値やゲームの演出と切り離し、済んだ件数だけを数えます
- **図鑑・成長・1日の記録**：倒した影、合格の見込みの推移、章ごとの正答率、斬り跡の暦、毎晩の記録
- **PC**：左のメニュー、今日の右側のパネル、やることの引き出し。J/K で選ぶ、X で斬る、S で明日へ、⌘K（Ctrl+K）で検索、1/2 で手帳の切りかえ
- **オフライン**：アプリ本体と資格パックを端末に保存するので、通信がなくても学習とやることは使えます

## データと AI の約束

- 個人の手帳と仕事の手帳は、端末でもクラウドでも別々に保存し、書き出しと削除も別々にできます
- 同期と AI の自動実行は、どちらも最初はオフです。オンにするのは手帳ごと、項目ごとの同意のあとです
- AI に何を送るかは、設定の画面に項目ごとに書いてあります。仕事の手帳の中身は、AI の段取り（送る前に中身を確かめる画面を通ったもの）以外では送りません
- AI は提案だけをします。AI の案は、受け入れたときにやることに加わり、済んだ扱いにするのは本人だけです
- AI のキーはサーバー（Vercel の環境変数）にだけ置き、ブラウザには渡しません
- AI が使えないとき（未設定、オフライン、上限、障害）も、記録やまとめは端末の中で書き、手で操作できます
- 経験値やレベルは本人のためのもので、職場での評価や人との比較に使うものではありません

## 開発

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest
npm run build      # 型チェックのあと dist/ に出力（sw.js も生成）
```

AI の関数（`api/`）を手元で試すときは `npx vercel dev` を使います。

## 公開（Vercel）

リポジトリを Vercel に接続すると、`vercel.json` のとおり `npm run build` でビルドされます。環境変数は次のとおりです。どれも未設定のままでも、AI と同期のないアプリとして動きます。

| 変数 | 使い道 |
|---|---|
| `ANTHROPIC_API_KEY` | AI を使うときに必要。サーバー側だけで読みます |
| `ZAN_MODEL` | 使うモデルを変えるとき。省略時は `api/_lib/claude.js` の既定 |
| `VITE_FIREBASE_API_KEY` `VITE_FIREBASE_AUTH_DOMAIN` `VITE_FIREBASE_PROJECT_ID` `VITE_FIREBASE_APP_ID` | Google ログインと同期（ビルド時に埋め込まれる、公開してよい値） |
| `FIREBASE_PROJECT_ID` | サーバーがログインのトークンを確かめるため。省略時は `VITE_FIREBASE_PROJECT_ID` |
| `FIREBASE_SERVICE_ACCOUNT` | AI の利用回数を Firestore に記録するため（JSON か、その base64）。ないときはサーバーのメモリに数えます |
| `ZAN_ALLOWED_EMAILS` | AI を使える人をメールアドレスで絞る（カンマ区切り） |
| `ZAN_ALLOW_ANON_AI` | `1` で、ログインなしでも AI を使える（IP ごとの上限つき）。Firebase を設定しないときの試用向け |
| `ZAN_AI_MONTHLY` `ZAN_AI_MONTHLY_ANON` `ZAN_AI_MONTHLY_TOTAL` | 1人あたり・ログインなし・全員あわせての月の上限（既定 120・20・3000）。1分に 6回までの制限もあります |

AI を使うには、`ANTHROPIC_API_KEY` に加えて、だれが使えるかの設定（Firebase の値か `ZAN_ALLOW_ANON_AI=1`）が必要です。どちらもないと、キーがあっても AI はオフのままです。

Firebase を使うときは、Authentication で Google を有効にし、承認済みドメインに公開先を足してから、Firestore のルールを反映します。

```sh
npx firebase-tools deploy --only firestore:rules --project <プロジェクトID>
```

ルール（`firestore.rules`）は、本人の `users/{uid}/books/{p|w|profile}` だけを読み書きできるようにしています。サーバー側の API も、ログインのトークンと回数の上限を毎回確かめます。

### 費用の上限

アプリ側の上限に加えて、Anthropic Console でも月の利用上限（spend limit）を設定してください。`FIREBASE_SERVICE_ACCOUNT` がないとき、回数はサーバーの再起動で数え直しになります。

AI への問い合わせは、安全上の理由で断られたときに、Anthropic が勧めるモデルでサーバー側で自動的にやり直す設定（`fallbacks: "default"`）にしています。やり直しても断られたときは、端末で書いた文や公式の解説をそのまま使います。

## 資格パック

資格ごとの問題と分野は `public/certs/` の JSON です。新しい資格を受けるときは、ファイルを足して `public/certs/index.json` に登録します（`version` で版を管理）。サービスワーカーは、ビルドのたびに中身から版を作り直します。

## フォルダ

- `src/core/` 手帳のルール（やること、経験値、学習、影、成長、記録、同期、書き出し）。画面から切り離してあり、`tests/` で確かめています
- `src/screens/` スマホの各画面、`src/pc/` PC のレイアウト、`src/ui/` 共通の部品と演出、`src/styles/` 見た目
- `api/` Vercel の関数（`ai` 毎晩のまとめ・AI の案・影の名前・仕事の段取り、`tutor` 解説、`status` AI が使えるか）。`api/_lib/` に送る中身の検査、ログインの確認、回数の上限
